Role: first independent adversarial reviewer.

After accepting the package binding, inspect the exact frozen diff plus only the imported/certified definitions necessary to falsify it.

Mandatory review themes, when applicable:
- owner/taxonomy collision or accidental narrowing of an existing owner;
- valid-state rejection and invalid-state acceptance;
- A/B logical-identity collisions across every retained static dimension;
- exact-type, malformed/fabricated/post-construction-corrupted state;
- deterministic ordering/canonicalization laws;
- hidden temporal/runtime/operational authority;

- documentation overclaims relative to source.
