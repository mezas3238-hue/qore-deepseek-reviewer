The existing CA-01..CA-18 architecture remains authoritative. Do not replace it with a second architecture. Implement these capabilities as coherent extensions of the existing substrates, using new focused modules only where that reduces coupling and makes invariants clearer.

## 3.1 Explicit Causal Reasoning

CIBO must be able to distinguish correlation/association from causal claims and retain competing causal hypotheses.

Minimum semantics:
- typed causal hypothesis/claim identity and lifecycle linkage;
- causes/effects/context/confounders or equivalent typed representation;
- evidence-for, evidence-against, contradiction, limitations;
- causal claim strength must never exceed evidence sufficiency;
- competing causal explanations remain representable simultaneously;
- intervention/outcome correlation must not automatically become causal attribution;
- causal falsification/supersession is deterministic and auditable;
- exact runtime types, canonical ordering, immutable state, replay-safe fingerprints.

Mandatory adversarial classes:
- correlation masquerading as causation;
- post-hoc/hindsight evidence laundering;
- confounder omission;
- evidence swapping/staleness/version mismatch;
- contradictory causal hypotheses;
- fabricated causal certainty;
- subclass/bool laundering and retained-state corruption.

## 3.2 Multi-Scenario Mental Simulation

Before a material cognitive recommendation/conclusion, CIBO must be able to model plausible alternatives without treating simulations as facts.

Required scenario families include at least:
- base;
- adverse;
- extreme/stress;
- regime-change / structural-transition.

Minimum semantics:
- scenario identity/version and explicit assumptions;
- source evidence/world-model binding;
- hypothetical state clearly separated from observed fact;
- comparable alternatives/actions or abstention;
- explicit uncertainties/limitations and missing evidence;
- deterministic scenario ordering/fingerprints/replay;
- no fabricated probability if no calibrated probability evidence exists;
- scenario output is advisory cognition only, never execution authority.

Adversarial classes:
- scenario-as-fact laundering;
- stale world snapshot;
- hidden current time/RNG;
- optimistic scenario dominance/fake consensus;
- impossible/contradictory assumptions;
- copied scenario id with changed content;
- probability/confidence laundering.

## 3.3 Strong Metacognition

CIBO must evaluate whether it is using the correct reasoning process for the problem, not merely whether the final answer looks plausible.

Minimum semantics:
- introspect current reasoning mode and evidence sufficiency at an engineering-evidence level (never expose private chain-of-thought);
- identify missing specialist perspectives/evidence/critic activity;
- detect insufficient reasoning, unnecessary escalation, unresolved contradiction and calibration mismatch;
- recommend/derive a bounded reasoning transition among `FAST / HIGH / MAX / COUNCIL_ADVERSARIAL` under deterministic policy inputs;
- permit abstention/request-evidence when cognition is underdetermined;
- meta-evaluation must not self-certify authority or fabricate evidence;
- record auditable reason codes/inputs, not private chain-of-thought.

Adversarial classes:
- self-confidence as evidence;
- recursive infinite escalation;
- MAX == authority laundering;
- council invocation manufacturing consensus;
- missing-specialist suppression;
- replay producing a different escalation from identical inputs.

## 3.4 Persistent Hypothesis Lifecycle

CIBO hypotheses must have a durable, replayable lifecycle instead of being disposable text.

Required lifecycle must represent at least:
`BORN -> ACTIVE/UNDER_TEST -> CONFIRMED | REFUTED | INCONCLUSIVE -> REVISED/SUPERSEDED`
(or an equivalent typed model with the same semantics).

Minimum semantics:
- stable hypothesis identity and revision/version lineage;
- proposition/content fingerprint;
- evidence for/against, contradictions, tests/experiments/research references;
- confidence/calibration bounded by evidence state;
- explicit supersession chain with cycle prevention;
- no mutation-in-place of prior historical versions;
- causal hypotheses may participate without making all hypotheses causal;
- replay/audit reconstructs exactly why state transitioned;
- invalid direct terminal-state construction without required evidence fails closed.

Adversarial classes:
- direct `CONFIRMED` fabrication;
- evidence removal after confirmation;
- refuted hypothesis resurrected without a new revision/evidence;
- supersession cycles;
- id/version swap;
- same id/content mismatch;
- conflicting evidence ignored;
- boolean `proven` laundering.
